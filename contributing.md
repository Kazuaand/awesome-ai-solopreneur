# Contribution Guidelines

Thanks for helping. This list stays small on purpose: an entry earns its place by being useful to someone who runs a business alone with AI agents.

## Adding an entry

- Use one pull request per entry, and explain how you have used it.
- Format: `- [Name](https://link) - What makes it good, in one or two sentences.` Start the description with a capital letter and end it with a period.
- Link to the original public source. No paywalled, members-only or login-only pages, and no affiliate or tracking links.
- Check that the link works and points to an active project or a page that still exists.
- Put new entries at the end of the right section unless order matters for reading.
- Never include secrets, personal data, or anyone's private information.

## Translations

- `README.md` (English) is the source. Translations live next to it as `README.<language>.md` (for example `README.ja.md`).
- Keep the same sections, the same item order and the same links in every language, so each line maps to the same line in the source.
- Write naturally for readers of that language instead of translating word by word. Keep product and project names as they are.
- Do not translate code, file names or tag names (for example `og:description`).
